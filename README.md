# guacamole-cats

Katzen-Nacht: ein Dark-Theme mit Katzenmotiven als Extension für [Apache Guacamole](https://guacamole.apache.org/). Deutsch und Englisch.

## Installation

1. Den Inhalt dieses Repos als `.jar` (ZIP) packen:
   ```
   zip -r guacamole-cat-theme.jar .
   ```
2. Die Datei in das Guacamole-Extensions-Verzeichnis kopieren (z. B. `/etc/guacamole/extensions/`).
3. Guacamole bzw. den Servlet-Container neu starten.
